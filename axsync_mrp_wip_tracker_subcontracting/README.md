# WIP Tracker Subcontract (bridge module)

Auto-installs when both `axsync_mrp_wip_tracker` and `mrp_subcontracting` are installed. Adds the subcontractor field, a Subcontracted flag and filter, a Subcontractor group-by, and the Open subcontracting orders dashboard tile. Distributed under OPL-1 together with the main module.
